# Diseño mecánico del robot

En esta carpeta se incluirán los diseños mecánicos necesarios para la construcción del robot.

## Contenido

- Modelos 3D del chasis.
- Archivos de impresión 3D.
- Diseños estructurales del robot.

## Descripción

La parte mecánica del robot se centra en el diseño del chasis, estructura y adaptación de componentes para garantizar estabilidad y correcto ensamblaje.
