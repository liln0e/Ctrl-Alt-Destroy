# Diseño electrónico del robot

En esta carpeta se incluye la documentación electrónica necesaria para el desarrollo del robot BattleBot del equipo **Ctrl+Alt+Destroy**.

## Contenido

Los siguientes archivos corresponden al diseño electrónico realizado en **KiCad**:

- `sumo_robot.kicad_sch` → Esquemático electrónico del circuito.
- `sumo_robot.kicad_pcb` → Diseño de la PCB del robot.
- `sumo_robot.kicad_pro` → Archivo del proyecto de KiCad.

## Diseño electrónico

La PCB ha sido diseñada para integrar los componentes electrónicos necesarios para el funcionamiento del robot, incluyendo:

- Alimentación del sistema.
- Integración del microcontrolador ESP32.
- Conexiones para sensores.
- Control de actuadores y elementos electrónicos del robot.

El diseño electrónico se ha realizado utilizando **KiCad**, permitiendo la organización de conexiones, distribución de componentes y fabricación de una PCB personalizada.

Las imágenes del diseño de la PCB y de la placa fabricada pueden consultarse en la documentación web del proyecto.
