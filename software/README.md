# Software del robot

En esta carpeta se incluye el código fuente y la documentación relacionada con el funcionamiento del robot BattleBot del equipo **Ctrl+Alt+Destroy**.

## Contenido

- `sumo_robot_final.ino` → Código principal del robot.

## Descripción

El software del robot será el encargado de controlar la lógica general de funcionamiento, permitiendo la comunicación entre sensores, actuadores y componentes electrónicos del sistema.

Entre sus funciones se incluyen:

- Control del movimiento del robot.
- Lectura y gestión de sensores.
- Coordinación del comportamiento general del sistema.
- Pruebas y ajustes del funcionamiento durante el desarrollo.

El código del robot ha sido desarrollado conjuntamente entre los integrantes del equipo y podrá actualizarse conforme avance el proyecto.
